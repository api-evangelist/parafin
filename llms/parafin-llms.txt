# Parafin

> Parafin is an embedded finance infrastructure company (founded 2020) that lets software platforms, marketplaces, and payment service providers offer capital, spend, and pay-over-time products to the small businesses on their platform. Parafin abstracts capital sourcing, compliance, underwriting/risk, servicing, and collections behind white-labeled REST APIs and embeddable Parafin Elements widgets (React, Vue, Angular). Notable customers include DoorDash and Mindbody.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public catalog and Parafin's public developer surface; Parafin's own docs host is login-gated and does not publish a machine-readable llms.txt.

## API

- [Parafin API (docs)](https://docs.parafin.com/): White-labeled embedded finance REST API. Production host https://api.parafin.com, sandbox host https://api.dev.parafin.com. OAuth client-credentials auth; short-lived bearer token via POST /v1/auth/redeem_token.

## Products

- Capital: revenue-based cash advances and flex term loans embedded in the platform
- Line of Credit: revolving credit for merchants
- Spend: card and cash account
- Pay Over Time: installment payments at checkout
